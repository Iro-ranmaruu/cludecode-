# WiSM製品アプリ

社員番号とパスワードでログインし、WiSM製品に関する3つの申請・依頼を行える社内アプリです。

- **特価申請**: WiSM商品の特別価格申請（元Excelテンプレートの Sheet1 相当）
- **不具合処理依頼**: WiSM製品の不具合品について処理を依頼（元Excelテンプレート wfi001 相当）
- **サンプル依頼**: WiSM製品のサンプル提供を申請

各モジュールとも、営業が新規申請を入力すると企画側の一覧に追加され、企画権限のユーザーが内容を確認して承認・却下・処理状況の更新を行えます。

## 構成

- Next.js（App Router）+ TypeScript + Tailwind CSS
- データ保存先は SQLite（`better-sqlite3`、`data/app.db` に保存。gitignore 対象）
- 認証はCookieセッション方式。初回は社員番号・氏名・店所名・メールアドレス・パスワード・権限（営業/企画）を登録すればすぐに使えます（`/login`）
- 特価申請・不具合処理依頼・サンプル依頼のいずれかで企画がステータスを更新すると、申請者に処理結果メールを自動送信します。
  宛先は人事台帳（`/employees`、企画権限のみ）に登録されたメールアドレスを優先し、登録がなければ申請者本人がアカウント登録時に
  入力したメールアドレスにフォールバックします（どちらもなければ送信をスキップします）
- 商品マスタ（`/master`、企画権限のみ）でメーカーコード＋商品コードに対応する商品名・梱包単位・通常仕切（営業仕切）・特価目安を登録すると、
  3モジュールすべての商品明細フォームでメーカーコード／商品コードを入力した際に商品名・梱包単位が自動反映されます。
  特価申請では通常仕切も自動入力され、希望仕切額の入力欄のそばに特価目安が参考表示されます
- `data-seed/product-master.csv` に実際の商品マスタデータ（648件、メーカーコード・商品コード・商品名・梱包単位・営業仕切・特価目安）を
  同梱しており、初回起動時に商品マスタが空であれば自動で取り込まれます
- 特価申請フォームでは、社員番号を入力すると人事台帳（`/employees`）を参照して担当者名・店所名・店所コード・所属長名が自動入力され、
  得意先コードを入力すると得意先マスタ（`/customers`）を参照して得意先施設名が自動入力されます。同様の自動入力は不具合処理依頼・
  サンプル依頼フォームの共通項目（社員番号→担当者名・店所名・店所コード・所属長名、得意先コード→得意先施設名。サンプル依頼は
  社員番号→氏名・部署のみ）にも適用されています
- 特価申請フォームで、通常仕切りを基準に納入価の粗利を計算した際に15%以上になる商品行がある場合、送信時に確認ポップアップを表示します
  （ムトウ全体の利益確保のため、その水準の粗利があれば特価申請は不要という案内）。ポップアップでは「納入価を訂正する」（入力画面に戻る）
  か「特価申請を終了する」（メインメニューに戻る）を選べます
- 特価申請の必須項目は「申請日・社員番号・得意先コード・メーカーコード・商品コード・納入価・特価目安・特価申請理由」の8項目です。
  未入力のまま送信しようとするとエラー表示で入力を促し、フォーム上部の進捗バーで入力状況を確認できます（特価申請・不具合処理依頼・
  サンプル依頼の3フォームすべてに搭載）
- 各モジュールの申請データはCSVで一括ダウンロードできます（企画権限のみ。メインメニューまたは各処理状況一覧ページから）。
  企画権限以外のユーザーがエクスポートAPI（`/api/export/{tokka,fuguai,sample}`）に直接アクセスした場合もサーバー側で403を返し拒否します。
  特価申請・不具合処理依頼は申請日の期間、サンプル依頼は申請日の期間に加えて申請先（北海道／東京／大阪／九州）でも絞り込んでダウンロードでき、
  期間未指定・申請先すべて選択で全期間・全国分がダウンロードされます

## 画面構成

- `/login`: ログイン・新規登録
- `/`: メインメニュー（3モジュールへのリンク、企画権限なら商品マスタへのリンクも表示）
- `/tokka/new`, `/tokka/requests`, `/tokka/requests/[id]`: 特価申請
- `/fuguai/new`, `/fuguai/requests`, `/fuguai/requests/[id]`: 不具合処理依頼
- `/sample/new`, `/sample/requests`, `/sample/requests/[id]`: サンプル依頼
- `/master`: 商品マスタ管理（企画権限のみ。CSV一括インポートにも対応）
- `/employees`: 人事台帳（社員名簿）管理（企画権限のみ。CSV一括インポートにも対応）
- `/customers`: 得意先マスタ管理（企画権限のみ。CSV一括インポートにも対応）

営業権限のユーザーは自分が申請したものだけが一覧に表示され、詳細画面は閲覧のみ（承認操作は企画権限のみ）です。

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。初回アクセス時に `data/app.db` が自動作成されます。

## ビルド

```bash
npm run build
npm start
```

## 単体版（Node.js不要、参考）

`standalone/index.html` はNode.js不要の単一HTML版です。ログイン→メインメニュー→特価申請／不具合処理依頼／サンプル申請の3モジュールへ分岐する、
本体と同じ画面フローをブラウザの`localStorage`だけで再現しており、商品マスタ・人事台帳・得意先マスタによる自動入力、必須項目の
入力進捗バー・エラー表示、企画権限のみが使えるCSVエクスポートも含まれています（人事台帳は社員番号4908→氏名「イイダ」等、
得意先マスタは得意先コードTL9999→「WiSM病院」の例をあらかじめ内蔵）。ログイン情報も含めすべてブラウザ内のみに保存されるため、
実運用のセキュリティはなく、他の人・他の端末とはデータが共有されません。操作感を一人で手早く確認したい場合にご利用ください。本番運用には上記のNext.js版をお使いください。

## 商品マスタの更新

商品マスタを更新する場合は `/master` から以下いずれかの方法で登録してください（`メーカーコード+商品コード` が既存の場合は上書きされます）。

- CSV一括インポート: `メーカーコード,商品コード,商品名,梱包単位,営業仕切,特価目安` の順（営業仕切・特価目安は省略可）
- 1件ずつ登録フォーム

初回起動時に自動投入される `data-seed/product-master.csv` を直接編集してコミットしても構いません（次回、商品マスタが空の状態でアプリを起動したときに反映されます。既にデータが入っているDBには自動反映されないため、その場合は上記のCSVインポートをお使いください）。

## 人事台帳の更新

人事台帳（処理結果メールの宛先、および特価申請フォームでの社員番号による自動入力に使用）は `/employees` から以下いずれかの方法で
登録してください（社員番号が分かる場合はそれで、分からない場合は氏名で既存行を上書きします）。

- CSV一括インポート: `社員番号,氏名,メールアドレス,店所名,店所コード,所属長名` の順（社員番号・店所名・店所コード・所属長名は省略可）
- 1件ずつ登録フォーム

初回起動時に自動投入される `data-seed/employee-directory.csv` を直接編集してコミットしても構いません
（次回、人事台帳が空の状態でアプリを起動したときに反映されます。既にデータが入っているDBには自動反映されないため、
その場合は上記のCSVインポートをお使いください）。

## 得意先マスタの更新

特価申請フォームで得意先コードから得意先施設名を自動入力するための得意先マスタは `/customers` から以下いずれかの方法で登録してください。

- CSV一括インポート: `得意先コード,得意先施設名` の順
- 1件ずつ登録フォーム

初回起動時に自動投入される `data-seed/customer-master.csv` を直接編集してコミットしても構いません（人事台帳・商品マスタと同様、
既にデータが入っているDBには自動反映されないため、その場合は上記のCSVインポートをお使いください）。

## メール通知の設定

処理結果の自動メール送信にはSMTPを使用します。以下の環境変数を`.env.local`等に設定してください（未設定の場合は送信をスキップし、
サーバーログに送信予定だった宛先・件名を出力するだけの動作になります。会社のメールサーバー・Gmail（アプリパスワード）・SendGrid等、
SMTPに対応したものであれば利用できます）。

```
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_SECURE=false
SMTP_USER=your-user
SMTP_PASS=your-password
MAIL_FROM="WiSM製品アプリ <no-reply@example.com>"
```
