# WiSM製品アプリ

社員番号とパスワードでログインし、WiSM製品に関する3つの申請・依頼を行える社内アプリです。

- **特価申請**: WiSM商品の特別価格申請（元Excelテンプレートの Sheet1 相当）
- **不具合処理依頼**: WiSM製品の不具合品について処理を依頼（元Excelテンプレート wfi001 相当）
- **サンプル依頼**: WiSM製品のサンプル提供を申請

各モジュールとも、営業が新規申請を入力すると企画側の一覧に追加され、企画権限のユーザーが内容を確認して承認・却下・処理状況の更新を行えます。

## 構成

- Next.js（App Router）+ TypeScript + Tailwind CSS
- データ保存先は SQLite（`better-sqlite3`、`data/app.db` に保存。gitignore 対象）
- 認証はCookieセッション方式。初回は社員番号・氏名・店所名・パスワード・権限（営業/企画）を登録すればすぐに使えます（`/login`）
- 商品マスタ（`/master`、企画権限のみ）でメーカーコード＋商品コードに対応する商品名・梱包単位・通常仕切（営業仕切）・特価目安を登録すると、
  3モジュールすべての商品明細フォームでメーカーコード／商品コードを入力した際に商品名・梱包単位が自動反映されます。
  特価申請では通常仕切も自動入力され、希望仕切額の入力欄のそばに特価目安が参考表示されます
- `data-seed/product-master.csv` に実際の商品マスタデータ（648件、メーカーコード・商品コード・商品名・梱包単位・営業仕切・特価目安）を
  同梱しており、初回起動時に商品マスタが空であれば自動で取り込まれます
- 各モジュールの申請データはCSVで一括ダウンロードできます（企画権限のみ。メインメニューまたは各処理状況一覧ページから）。
  企画権限以外のユーザーがエクスポートAPI（`/api/export/{tokka,fuguai,sample}`）に直接アクセスした場合もサーバー側で403を返し拒否します

## 画面構成

- `/login`: ログイン・新規登録
- `/`: メインメニュー（3モジュールへのリンク、企画権限なら商品マスタへのリンクも表示）
- `/tokka/new`, `/tokka/requests`, `/tokka/requests/[id]`: 特価申請
- `/fuguai/new`, `/fuguai/requests`, `/fuguai/requests/[id]`: 不具合処理依頼
- `/sample/new`, `/sample/requests`, `/sample/requests/[id]`: サンプル依頼
- `/master`: 商品マスタ管理（企画権限のみ。CSV一括インポートにも対応）

営業権限のユーザーは自分が申請したものだけが一覧に表示され、詳細画面は閲覧のみ（承認操作は企画権限のみ）です。

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。初回アクセス時に `data/app.db` が自動作成されます。

## ビルド

```bash
npm run build
npm start
```

## 単体版（Node.js不要、参考）

`standalone/index.html` はNode.js不要の単一HTML版です。ログイン→メインメニュー→特価申請／不具合処理依頼／サンプル申請の3モジュールへ分岐する、
本体と同じ画面フローをブラウザの`localStorage`だけで再現しており、商品マスタ（メーカーコード＋商品コードによる商品名・販売単位・JANコード・通常仕切の自動入力）や、
企画権限のみが使えるCSVエクスポートも含まれています。ログイン情報も含めすべてブラウザ内のみに保存されるため、
実運用のセキュリティはなく、他の人・他の端末とはデータが共有されません。操作感を一人で手早く確認したい場合にご利用ください。本番運用には上記のNext.js版をお使いください。

## 商品マスタの更新

商品マスタを更新する場合は `/master` から以下いずれかの方法で登録してください（`メーカーコード+商品コード` が既存の場合は上書きされます）。

- CSV一括インポート: `メーカーコード,商品コード,商品名,梱包単位,営業仕切,特価目安` の順（営業仕切・特価目安は省略可）
- 1件ずつ登録フォーム

初回起動時に自動投入される `data-seed/product-master.csv` を直接編集してコミットしても構いません（次回、商品マスタが空の状態でアプリを起動したときに反映されます。既にデータが入っているDBには自動反映されないため、その場合は上記のCSVインポートをお使いください）。
