# WiSM特価申請システム

営業がWiSM商品の特別価格申請（元Excelテンプレートの Sheet1 相当）をWeb上で入力し、
企画側が申請一覧を確認して商品明細ごとに承認・却下・金額変更を行えるアプリです。

## 構成

- Next.js（App Router）+ TypeScript + Tailwind CSS
- データ保存先は SQLite（`better-sqlite3`、`data/app.db` に保存。gitignore 対象）
- 画面
  - `/`: トップ
  - `/new`: 営業向け新規申請フォーム（商品明細・得意先コードは行を自由に追加/削除できます）
  - `/requests`: 企画向け申請一覧（ステータス表示）
  - `/requests/[id]`: 申請詳細。企画側はここで商品明細ごとに「承認・却下・金額変更」を選択し、
    決定仕切額の入力・備考の記入ができます。申請全体のステータスは商品明細の判定結果から自動算出されます。

## 開発

```bash
npm install
npm run dev
```

[http://localhost:3000](http://localhost:3000) を開いてください。初回アクセス時に `data/app.db` が自動作成されます。

## ビルド

```bash
npm run build
npm start
```
