# 動画 → マニュアル自動生成アプリ

指定したフォルダにある動画を **30MB 以内のファイルに分割**し、各パートから代表的な
フレーム（挿画・画面の切り替わり）を抽出、**OCR でテキストを解析**して、時系列の
**HTML マニュアル**を自動生成するローカル Streamlit アプリです。

## クイックスタート（Windows・一番簡単な方法）

1. 下記リンクを開き、緑色の「Code」ボタン →「Download ZIP」でダウンロードする
   （GitHubにログインが必要な場合はログインしてください）
   https://github.com/Iro-ranmaruu/cludecode-/tree/claude/video-split-analysis-manual-app-09qhu3
2. ダウンロードした ZIP ファイルを右クリック →「すべて展開」で、デスクトップなど
   分かりやすい場所に展開する
3. 展開したフォルダの中の `video_manual_app` フォルダを開く
4. その中の **`start_windows.bat`** をダブルクリックする

初回は Python・ffmpeg・Tesseract のインストールが必要な場合、画面にインストール先の
リンクが表示されるので、案内に従ってインストールしてから、もう一度
`start_windows.bat` をダブルクリックしてください。すべて揃っていれば、自動的に
ブラウザでアプリが開きます。

## 仕組み

1. **分割 (splitter)**: 動画がすでに 30MB 以下ならそのまま利用。超える場合は
   ffmpeg で 1 回だけ再エンコードし（映像ビットレート指定 + VBV 制御）、
   `-f segment -c copy` で高速に切り出すことで、各パートを確実に上限サイズ以内に
   収めます（安全マージン込み）。
2. **挿画（フレーム）抽出 (frame_extractor)**: ffmpeg のシーン変化検出
   (`select='gt(scene,T)'`) で画面が切り替わった瞬間のフレームを抽出します。
   変化が少ない動画（静止画primaryなプレゼン等）では自動的に一定間隔サンプリングに
   切り替わります。
3. **OCR 解析 (ocr_analyzer)**: 各フレームを Tesseract OCR（`jpn+eng`）でテキスト化
   します。Tesseract が未インストールの場合は自動的にスキップし、画像のみのマニュアル
   になります（処理自体は止まりません）。
4. **マニュアル生成 (manual_builder)**: 全パートのフレームを元動画の時系列順に並べ、
   スクリーンショット（base64埋め込み）+ 抽出テキストをまとめた単一の HTML ファイルを
   出力します。

出力は `output/<動画名>/` 以下に生成されます:

```
output/
  サンプル動画/
    chunks/                  # 30MB以内に分割された mp4
      サンプル動画_part000.mp4
      サンプル動画_part001.mp4
    frames/                  # 抽出されたフレーム画像（中間ファイル）
    サンプル動画_manual.html # 完成したマニュアル
```

## 動作環境について（重要）

このアプリは、動画ファイルにアクセスできる**ユーザー自身の PC** で実行してください。
クラウド上のサンドボックス環境（このセッションなど）からはユーザーのローカルフォルダに
到達できないため、動画の処理はできません。

デフォルトの動画フォルダは `app.py` 内の `DEFAULT_SOURCE_FOLDER` に設定済みです
（`VIDEO_SOURCE_FOLDER` 環境変数で上書き可能）。フォルダの場所が変わった場合は、
アプリ起動後にフォーム欄で直接書き換えるか、この変数を設定してください。

```powershell
# 例: PowerShell で一時的に上書きして起動する場合
$env:VIDEO_SOURCE_FOLDER = "C:\Users\4908\Desktop\どうがおきば"
streamlit run app.py
```

## セットアップ

### システム依存パッケージ（必須）

- **ffmpeg / ffprobe**（動画の分割・フレーム抽出に必須）
- **tesseract-ocr**（OCR。未インストールでも動作しますが文字抽出はされません）

Debian/Ubuntu の例:

```bash
sudo apt-get update
sudo apt-get install -y ffmpeg tesseract-ocr tesseract-ocr-jpn
```

macOS (Homebrew):

```bash
brew install ffmpeg tesseract tesseract-lang
```

### Python 依存パッケージ

```bash
cd video_manual_app
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

## 起動方法

```bash
streamlit run app.py
```

ブラウザが開いたら:

1. 動画が入っているフォルダの**絶対パス**を入力
2. 出力先フォルダ・分割サイズ上限・ビットレート・シーン検出感度・OCR言語などを調整
3. 「🚀 処理開始」を押す

処理が終わると、動画ごとに結果が展開表示され、HTML マニュアルのダウンロードと
プレビューができます。

## 主な設定項目

| 項目 | 説明 |
|---|---|
| 分割後の上限サイズ (MB) | 既定 30MB。分割ファイル1本あたりの目標上限。 |
| 目標映像ビットレート (kbps) | 再エンコード時の映像ビットレート。上限サイズに対して高すぎる場合は自動的に下げられます。 |
| シーン変化検出のしきい値 | 低いほど小さな変化でもフレームを抽出（枚数が増える）。 |
| フォールバック間隔（秒） | シーン変化がほぼ検出されない動画で、代わりに何秒おきにフレームを抜くか。 |
| OCR言語 | `jpn+eng` / `jpn` / `eng` から選択。 |

## 制限事項・既知の注意点

- ffmpeg の VBV レート制御には多少の変動があるため、まれに分割後ファイルが
  上限をわずかに超えることがあります。その場合はマニュアル上部に警告が表示されます
  （目標ビットレートを下げて再実行すると解消しやすくなります）。
- Tesseract の日本語言語データ (`tesseract-ocr-jpn`) が入っていない環境では、
  英語のみでの OCR、またはテキスト抽出なしで動作します。
- 大量 / 長時間の動画はエンコードに時間がかかります（一度だけ全体を再エンコードし、
  その後は高速なストリームコピーで分割するため、極端に遅くはなりません）。
